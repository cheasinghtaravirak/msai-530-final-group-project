Group Project – Key Instructions
Advanced Programming | Microservices, AI and Reporting

Project: Multi-Branch Shop Order Management System

Key Requirements
Group Project: Students must work in groups of 3–5 members.

Complete All 5 Tasks: Each group must design and implement a microservices-based system covering:

Task 1: Service Decomposition

Task 2: Database Conceptual Design

Task 3: Service Communication Matrix

Task 4: Data Pipeline and Aggregation

Task 5: AI and Reporting Integration

Implementation: Each group must develop working source code based on its proposed architecture and demonstrate the key functionalities.

Submission: Each group must submit:

Complete source code

Architecture diagrams and technical documentation

Presentation slides

Working system demonstration

Presentation & Demo: Each group will have 15 minutes to present its architecture, explain key design decisions, and demonstrate the implemented system.

Deadline
4 December 2026 (Friday) – Final submission, group presentation, and live demonstration.

Important: All five tasks are mandatory. Each group member is expected to contribute to the project and participate in the final presentation or demonstration.
